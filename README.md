## ✨ Features

| Feature | Description |
|---------|-------------|
| 🤖 **AI-Powered Responses** | Uses Llama 3 via Ollama for natural conversations |
| 📚 **RAG Architecture** | Retrieval-Augmented Generation with ChromaDB vector store |
| 💬 **Beautiful UI** | Modern React interface with Tailwind CSS |
| 🚀 **Fast API** | FastAPI backend with streaming support |
| 🔒 **100% Private** | Runs locally - no data leaves your machine |
| 💰 **Zero API Costs** | No OpenAI API key needed - everything runs locally |
| 📱 **Responsive** | Works on desktop, tablet, and mobile |
| 🎨 **Customizable** | Easy to adapt for any business (not just dance schools) |
| 🔍 **Source Citations** | Shows which knowledge base entries were used |
| ⚡ **Real-time** | Fast responses with typing indicators |
| 🌐 **CORS Ready** | Pre-configured for frontend-backend communication |
| 🧪 **Tested** | Includes test questions and Postman collection |
